# Creditos dos Assets Visuais

Este arquivo registra os recursos visuais utilizados na integracao do layout do
projeto `CRUD_PIZZA` com o primeiro projeto da disciplina, `atividade_git`.

## Origem dos assets no projeto

Os arquivos visuais foram reaproveitados do repositorio:

```
https://github.com/SifWebTech/atividade_git
```

Eles foram copiados para:

```
src/main/webapp/imagens/
src/main/webapp/css/fontes/
```

## Identidade visual

Os seguintes recursos compoem a identidade da Iglesias Siqueira Pizzas. Sao
ilustracoes e fotos de marca desenhadas/produzidas para o projeto de referencia:

- `logo.svg`
- `brasao-forjado.svg`
- `b_iglesias.jpg`
- `b_siqueira.webp`
- `pizza-margherita.svg`
- `pizza-marinara.svg`
- `pizza-quattro-formaggi.svg`
- `pizza-capricciosa.svg`
- `pizza-diavola.svg`
- `pizza-prosciutto-rucola.svg`
- `UnifrakturMaguntia.woff2`

Esses elementos foram usados para manter a continuidade visual entre o site
estatico da pizzaria e o sistema CRUD administrativo.

## Uso no CRUD

No `CRUD_PIZZA`, os assets foram usados para:

- cabecalho com marca da pizzaria;
- favicon;
- cartoes da pagina inicial administrativa;
- identidade visual do CRUD;
- futura apresentacao HTML do trabalho.

## Observacao para a apresentacao

Na apresentacao HTML do trabalho, estes creditos devem aparecer em uma secao
propria ou em um rodape de creditos, deixando claro que o CRUD reaproveita o
layout e os assets do primeiro projeto para formar uma continuidade entre as
duas entregas.
